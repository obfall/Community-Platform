# メンバー管理

## 概要

コミュニティに所属するメンバー（ユーザー）を閲覧・管理する機能です。用途に応じて **2 つの画面** に分かれています。

- **メンバー一覧（`/members`）**: ログイン済みメンバーが互いのプロフィールを閲覧できる **公開ディレクトリ**。検索・並び替え・詳細閲覧・DM 開始ができます
- **メンバー管理（`/settings/members`）**: システム管理者・オーナー専用の **運営管理画面**。ロール／ステータスの変更、パスワード強制リセット、メールアドレス変更、カスタム属性値の編集、CSV エクスポートを行います

いずれの画面も、ユーザーの基本情報（名前・メール・ロール・ステータス・登録日）と、プロフィール・公開情報・所属・カスタム属性などの付随情報を扱います。ユーザー本体は `users` テーブルで管理され、削除は物理削除ではなく `deletedAt`（論理削除）で行います。

---

## ロールとステータス

### ロール（role）

| ロール    | 表示名         | 概要                                     |
| --------- | -------------- | ---------------------------------------- |
| `owner`   | オーナー       | コミュニティ運営者。管理機能を利用できる |
| `admin`   | システム管理者 | システム全体の管理者。最上位権限         |
| `member`  | メンバー       | 一般メンバー                             |
| `visitor` | ビジター       | 制限付きの閲覧者                         |

- ロールの上下関係により操作制限があります（後述「機能と権限」参照）。**オーナーはシステム管理者（admin）を操作・昇格できません**

### ステータス（status）

| ステータス  | 表示名 | ログイン可否 | 概要                           |
| ----------- | ------ | :----------: | ------------------------------ |
| `active`    | 有効   |      ○       | 通常の利用可能状態             |
| `suspended` | 停止   |      ×       | 一時的にアクセスを停止した状態 |
| `withdrawn` | 退会   |      ×       | 退会した状態                   |

- **ステータスが `active` 以外（停止・退会）のユーザーはログインできません**。認証系の 3 か所（ログイン時・トークン更新時・API リクエスト認証時）すべてで `active` 以外を拒否するため、停止・退会に切り替えると新規ログインが不可になるだけでなく、**発行済みのアクセストークンも次のリクエスト検証で失効**し、リフレッシュもできなくなります（即時遮断）
- **停止（suspended）と退会（withdrawn）はログイン挙動上の違いはありません**。どちらも「`active` ではない」＝アクセス不可で、意味づけ（一時停止か退会か）のみが異なります
- ステータス（`withdrawn`）は **論理削除（`deletedAt`）とは別のフラグ**です。退会にしてもレコードは残り、管理画面・CSV から参照できます。論理削除されたユーザーは各一覧・詳細から除外されます

## 機能と権限

| 操作                                    | 一般メンバー | システム管理者 | オーナー | 備考                                          |
| --------------------------------------- | :----------: | :------------: | :------: | --------------------------------------------- |
| メンバー一覧（`/members`）閲覧          |      ○       |       ○        |    ○     | ログイン済みなら誰でも。admin は一覧から除外  |
| メンバー詳細閲覧（公開ディレクトリ）    |      ○       |       ○        |    ○     | メール表示は admin のみ／公開情報は公開者のみ |
| DM（チャット）開始                      |      ○       |       ○        |    ○     | 自分以外のメンバーに対して                    |
| メンバー管理画面（`/settings/members`） |      ×       |       ○        |    ○     | 設定メニューは admin / owner のみ表示         |
| ロール変更                              |      ×       |       ○        |    ○     | 自分自身・owner→admin の操作は不可            |
| ステータス変更                          |      ×       |       ○        |    ○     | 自分自身・owner→admin の操作は不可            |
| パスワード強制リセット                  |      ×       |       ○        |    ○     | 自分自身・owner→admin の操作は不可            |
| メールアドレス変更                      |      ×       |       ○        |    ○     | 自分自身・owner→admin の操作は不可            |
| カスタム属性値の編集                    |      ×       |       ○        |    ○     | 管理者専用属性を含め編集可                    |
| メンバー CSV エクスポート               |      ×       |       ○        |    ○     | 全メンバー＋属性値を CSV 出力                 |

### 共通の操作制限（管理アクション）

ロール変更・ステータス変更・パスワード強制リセット・メールアドレス変更の 4 操作は、バックエンドの共通ガードで以下を必ず検証します。

- **自分自身に対しては実行できません**（`自分自身に対してこの操作は実行できません`）
- **オーナーはシステム管理者（admin）に対して実行できません**（`運営者はシステム管理者を操作できません`）
- 対象ユーザーが存在しない・論理削除済みの場合はエラー（`ユーザーが見つかりません`）

加えてロール変更では、**オーナーはメンバーを admin に昇格できません**（`運営者はシステム管理者に昇格させることはできません`）。

管理画面 UI 側でも、上記制限に該当する場合（自分自身・オーナーが admin を対象）は「パスワード強制リセット」「メールアドレス変更」ボタンを非表示にします。

| パスワードリセットの有効期限 | 発行から 60 分                                   |
| CSV 文字コード               | UTF-8 BOM 付き                                   |

## 詳細仕様

### 1. メンバー一覧（公開ディレクトリ `/members`）

ログイン済みメンバーが他のメンバーを探すための一覧画面です。

- **検索**: 名前で検索（サーバ側で全文検索）
- **並び替え**: ロール順 / 名前 A→Z / 名前 Z→A / 参加日が新しい順 / 参加日が古い順
- **表示列**: メンバー（アバター＋名前）・ロール・参加日
- **admin の非表示**: 一般メンバー一覧では **システム管理者（admin）を一覧から除外** します。クライアント側フィルタだとページネーション件数とズレるため、サーバ側（`excludeAdmin`）で除外します
- 各行から詳細ページ（`/members/{id}`）へ遷移できます

#### メンバー詳細（`/members/{id}`）

- **ヒーロー**: ヘッダー画像・アバター・名前・ロールバッジ・参加日、および「チャット」ボタン（自分以外に表示、押下で DM ルームを開始）
- **プロフィール情報**: 職業・出身国・参加日・所属。**メールアドレス行は admin のみ表示**
- **公開情報**: 公開ステータスが `public` のメンバーのみ表示。ニックネーム・活動拠点・専門分野・イベント役割・自己紹介・興味分野
- **イベント／プロジェクトタブ**: 参加イベント・参加プロジェクトの一覧

> この画面（`/members`・`/members/{id}`）は **i18n 化済み**（`messages/ja/members.json` を参照）です。

### 2. メンバー管理画面（`/settings/members`）

システム管理者・オーナー専用の運営画面です。設定レイアウトの `AdminGuard`（`owner` / `admin` のみ許可）配下にあります。

#### フィルター

| 項目       | 内容                                                  |
| ---------- | ----------------------------------------------------- |
| 名前で検索 | 入力後 300ms のデバウンスで検索（全文検索）           |
| ロール     | すべて / オーナー / 管理者 / メンバー / ビジター      |
| ステータス | すべて / 有効 / 停止中 / 退会済み（**初期値: 有効**） |

- ステータス未指定（「すべて」）でも、**論理削除済みユーザーは常に除外**されます
- ステータスを指定しない標準表示では、**有効・停止中のみ**を対象とし、退会済みは含めません（明示的に「退会済み」「すべて」を選ぶと表示）

#### 一覧テーブル

- **表示列**: メンバー（アバター＋名前）・メール・ロール・ステータス・登録日
- ステータスバッジは色分け（有効=既定 / 停止中=赤系 / 退会済み=アウトライン）。**停止中の行は淡色（グレー）表示**
- 検索時は名前のマッチ部分をハイライト表示
- 行クリックで「メンバー詳細ダイアログ」を開きます

#### メンバー詳細ダイアログ

ダイアログ上部に基本情報（アバター・名前・メール・ロールバッジ）と **管理アクション** を表示し、下部にタブ（詳細 / カスタム属性）を配置します。

**管理アクション**

| 操作                   | 内容                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| ロール変更             | オーナー / 管理者 / メンバー / ビジターから選択。「保存」で反映                                                            |
| ステータス変更         | 有効 / 停止 / 退会から選択。「保存」で反映                                                                                 |
| パスワード強制リセット | 確認ダイアログの後、対象ユーザーにパスワードリセットメールを送信。既存の未使用リセットリンクは失効。**制限対象では非表示** |
| メールアドレス変更     | 新アドレスと確認用の一致・形式・現行と異なることをチェックして変更。**制限対象では非表示**                                 |

- ロール・ステータスは変更があった項目のみ保存時に個別 API で更新します（両方変更した場合は並列送信）
- メールアドレス変更ダイアログには「変更後、対象ユーザーのセッションは全て無効化されます」と明記

**カスタム属性タブ**

- 対象メンバーのカスタム属性値を型（テキスト / 数値 / 日付 / 単一選択 / 複数選択）に応じたフォームで編集し、一括保存します
- 管理者は **管理者専用属性を含む全属性** を編集できます（属性が未定義の場合はその旨を表示）

#### CSV エクスポート

- 画面右上の「CSV エクスポート」ボタンで、全メンバーの一覧を CSV ダウンロードします
- **固定列**: 名前・メール・ロール・ステータス・ランク・登録日
- **カスタム属性列**: 定義済みの全カスタム属性を `sortOrder` 順に追加
- 論理削除済みユーザーを除く全メンバー（有効・停止・退会を含む）を登録日昇順で出力
- Excel での文字化けを防ぐため **UTF-8 BOM** を付与。ファイル名は `members_YYYYMMDD.csv`

## 各操作の副作用

### ステータス変更

- `active` 以外に変更した時点で対象ユーザーは実質的に即アクセス不可になります（ログイン・トークン更新・API 認証のすべてで拒否）

### メールアドレス変更

- 新アドレスの **一意性を検証**（既に使用されていれば `このメールアドレスは既に使用されています`）
- 現行アドレスと同一の場合は変更せず現状を返します
- 変更時にトランザクションで以下を実行:
  - `email` を更新し、**メール確認済みフラグ（`emailVerifiedAt`）をリセット**
  - 対象ユーザーの **有効なリフレッシュトークンをすべて失効**（全セッション無効化）
- **旧アドレスと新アドレスの両方に変更通知メールを送信**

### パスワード強制リセット

- 既存の未使用リセットトークンを失効させ、新しいトークン（**有効期限 60 分**）を発行
- 対象ユーザーのメールアドレスにリセットメールを送信

## API 一覧

### メンバー参照・管理（`users`）

| メソッド | パス                              | 権限          | 内容                                       |
| -------- | --------------------------------- | ------------- | ------------------------------------------ |
| `GET`    | `/users`                          | 認証          | メンバー一覧（検索・フィルタ・ページング） |
| `GET`    | `/users/:id`                      | 認証          | メンバー詳細（email は本人 / admin のみ）  |
| `GET`    | `/users/:id/events`               | 認証          | 参加イベント一覧                           |
| `GET`    | `/users/:id/projects`             | 認証          | 参加プロジェクト一覧                       |
| `PATCH`  | `/users/:id/role`                 | admin / owner | ロール変更                                 |
| `PATCH`  | `/users/:id/status`               | admin / owner | ステータス変更                             |
| `POST`   | `/users/:id/force-password-reset` | admin / owner | パスワード強制リセット                     |
| `PATCH`  | `/users/:id/email`                | admin / owner | メールアドレス変更                         |

### カスタム属性値・エクスポート（`users` / `member-attributes`）

| メソッド | パス                    | 権限          | 内容                                         |
| -------- | ----------------------- | ------------- | -------------------------------------------- |
| `GET`    | `/users/:id/attributes` | admin / owner | 対象メンバーの属性値（管理者専用属性を含む） |
| `PATCH`  | `/users/:id/attributes` | admin / owner | 属性値の一括設定（値 `null` で削除）         |
| `GET`    | `/users/export/csv`     | admin / owner | メンバー CSV エクスポート                    |

> 検索（`GET /users?search=`）は pgroonga による全文検索で、`users.name`・`user_public_info`（ニックネーム・自己紹介・専門分野・都道府県）・`user_affiliations`（組織名・肩書・役割）を横断してスコア順に返します。

## データの取り扱い

- **論理削除**: ユーザー削除は `deletedAt` による論理削除で、各一覧・詳細・属性値参照・CSV から除外されます。退会（`status = withdrawn`）とは別概念です
- **メールの取り扱い**: 一覧・詳細ともに、メールアドレスは **本人またはシステム管理者にのみ返却**します（プライバシー保護）
- **CSV**: 論理削除済みを除く全メンバーを対象に、固定列＋全カスタム属性を出力。UTF-8 BOM 付き
- **セッション無効化**: メールアドレス変更時に対象ユーザーのリフレッシュトークンを全失効。ステータスを `active` 以外にすると既存トークンも認証段階で失効します

---

## 連携・自動処理

- **認証との連動**: ステータス（`active` 判定）はログイン・トークン更新・JWT 検証の各所で参照され、`active` 以外を遮断します
- **メール送信**: メールアドレス変更通知・パスワードリセットメールはメール送信サービス経由で送出されます
- **DM 連携**: 公開ディレクトリの「チャット」ボタンから、対象メンバーとの DM ルームを開始します
- **カスタム属性連携**: カスタム属性の定義は「コミュニティ設定 > カスタム属性」で管理し、その値をメンバー管理画面・CSV で入出力します（属性の定義仕様は「コミュニティ設定」仕様書を参照）

## ご利用にあたっての留意事項

- **停止・退会は即時にアクセスを遮断します**。誤って自分以外の運営者を停止/退会にすると当該メンバーがログインできなくなるため、操作対象を十分確認してください
- **オーナーはシステム管理者（admin）を操作できません**。admin のロール変更・ステータス変更・パスワードリセット・メール変更・admin への昇格は、システム管理者のみが実行できます
- **メールアドレス変更は対象ユーザーの全セッションを無効化**し、メール確認済み状態もリセットします。変更後は本人による再ログインが必要です
- **メンバー管理画面（`/settings/members`）は現状 i18n 化されていません**（ラベルが日本語ハードコード）。公開ディレクトリ（`/members`）は i18n 化済みです
- 一覧の標準表示（ステータス未指定）は有効・停止中のみで、**退会済みメンバーはフィルタで明示選択しないと表示されません**
- ロール選択肢に表示される値は `owner` / `admin` / `member` / `visitor` の 4 種です（`moderator` はロール定義に存在しません）
