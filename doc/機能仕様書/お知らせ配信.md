# お知らせ配信

## 概要

管理者がコミュニティのメンバーへ、お知らせ・案内を一斉に配信するための機能です。配信対象（全員・イベント参加者など）と配信チャネル（アプリ内通知・メール・LINE）を指定して配信を作成・送信でき、配信ごとの送信状況（宛先・チャネル・ステータス）を確認できます。定型文を再利用するための「テンプレート」、メール配信を停止するアドレスを管理する「配信停止リスト」も備えています。

配信されたお知らせは、受信者側では **通知** として届きます（アプリ内通知の場合は通知ベル・通知一覧・ホームのお知らせウィジェットに表示されます）。受信側の挙動については別途「通知」機能仕様書をご参照ください。

配信には 2 つの入口があります。

- **全体配信**: サイドバー「配信」（`/broadcasts`）から、コミュニティ全体・特定条件のメンバーへ配信
- **イベント配信**: イベント詳細画面内の「配信」（`/events/:id/broadcasts`）から、当該イベントの申込者へ配信

---

## 機能と権限

本機能は **システム管理者・オーナー専用** です。一般ユーザーには表示されず、利用できません（機能全体が `mail_campaign` 機能フラグおよび管理者ロールで保護されています）。

| 操作                           | 一般ユーザー | システム管理者・オーナー | 備考                                               |
| ------------------------------ | :----------: | :----------------------: | -------------------------------------------------- |
| 配信一覧の閲覧                 |      ×       |            ○             | ステータスによる絞り込み可                         |
| 配信の作成・送信               |      ×       |            ○             | 作成と送信を一括で実行                             |
| 配信詳細（送信状況）の閲覧     |      ×       |            ○             | 受信者一覧・チャネル・ステータスを表示             |
| 送信実行（下書き・予約分）     |      ×       |            ○             | ステータスが「下書き」「予約済み」の配信のみ       |
| テンプレートの選択             |      ×       |            ○             | 配信作成時に定型文を読み込み                       |
| テンプレートの作成・編集・削除 |      ×       |            △             | API 提供済み。現状は管理画面 UI 未提供（留意事項） |
| 配信停止リストの管理           |      ×       |            △             | API 提供済み。現状は管理画面 UI 未提供（留意事項） |

## 制限値

| 項目                          | 値                             |
| ----------------------------- | ------------------------------ |
| 件名                          | 最大 200 文字                  |
| HTML 本文 / テキスト本文      | 文字数上限なし                 |
| テンプレート名                | 最大 100 文字                  |
| テンプレート件名              | 最大 200 文字                  |
| 一覧の 1 ページあたり表示件数 | 20 件                          |
| 配信詳細の受信者表示上限      | 200 件                         |
| 配信停止アドレスのメール形式  | メールアドレス形式（重複不可） |

## 詳細仕様

### 配信の作成

配信作成画面では、以下を指定して配信を作成します。

| 項目         | 形式             | 説明                                                        |
| ------------ | ---------------- | ----------------------------------------------------------- |
| 件名         | テキスト（必須） | 配信の件名                                                  |
| 配信チャネル | チェックボックス | アプリ内通知 / メール / LINE から選択（複数可）             |
| 本文         | テキストエリア   | チャネルにより入力欄が変化（下記参照）                      |
| テンプレート | セレクト（任意） | 選択すると件名・本文が自動入力される                        |
| 配信対象     | 固定表示         | 入口により自動決定（全体配信＝全員 / イベント配信＝申込者） |

- **配信チャネル**: 現状 **「アプリ内通知」のみ選択可能** です。「メール」「LINE」は選択不可（今後のフェーズで有効化予定）
- **本文の入力欄**: 「メール」チャネルを含む場合は「HTML 本文」＋「テキスト本文（任意）」を入力します。メールを含まない場合は「本文」（テキスト）のみを入力します
- **送信条件**: 件名の入力、チャネルの選択、および本文（メール含む場合は HTML 本文、含まない場合はテキスト本文）の入力が揃うと送信できます
- 配信作成画面の「配信を作成・送信」ボタンを押すと、**配信の作成と送信が一括で実行** され、送信後は配信詳細画面へ遷移します

### 配信対象（宛先）の決定

配信対象は、内部的に「配信対象種別（targetType）」で管理されます。

| 種別（targetType） | 対象範囲                                   | UI からの指定                      |
| ------------------ | ------------------------------------------ | ---------------------------------- |
| `all`              | ステータスが有効な全メンバー               | 全体配信で自動設定                 |
| `rank`             | 特定ランクのメンバー                       | 現状 UI 未対応（バックエンドのみ） |
| `custom`           | カスタム対象（現状は全員と同等・将来拡張） | 現状 UI 未対応                     |
| `event`            | 対象イベントの申込者（キャンセルを除く）   | イベント配信で自動設定             |

- **全体配信**: 宛先は「コミュニティ参加者全員」で固定表示されます（ランク・カスタム指定は今後の拡張予定）
- **イベント配信**: 宛先は「このイベントの申込者全員（キャンセル除く）」で固定表示されます
- 宛先解決時には、ステータスが有効（active）かつ未削除のユーザーのみが対象となります

### 配信スコープ

配信には 2 種類のスコープがあります。

| スコープ（scope） | 用途                     | 生成される通知種別   |
| ----------------- | ------------------------ | -------------------- |
| `global`          | コミュニティ全体への配信 | `announcement`       |
| `event`           | イベントに紐づく配信     | `event_announcement` |

- イベントスコープの配信では、配信対象種別が `event` であること、および対象イベントの指定が必須です（整合性チェックを行います）

### 配信ステータス

各配信は以下のステータスで管理されます。

| ステータス  | 表示名   | 説明                             |
| ----------- | -------- | -------------------------------- |
| `draft`     | 下書き   | 作成済みで未送信                 |
| `scheduled` | 予約済み | 配信予定日時を設定した未送信状態 |
| `sending`   | 送信中   | 送信処理の実行中                 |
| `sent`      | 送信済み | 送信が完了した                   |
| `failed`    | 失敗     | 送信に失敗した                   |

- 送信を実行できるのは、ステータスが **「下書き」または「予約済み」** の配信のみです
- 配信一覧はステータスによる絞り込みが可能です

### 配信詳細（送信状況）

配信詳細画面では、以下を確認できます。

- 件名・作成者・作成日時・配信チャネル・ステータス
- 本文（HTML 本文がある場合はサニタイズのうえ描画、ない場合はテキスト本文を表示）
- 受信者一覧（宛先メール・チャネル・配信ステータス・送信日時、最大 200 件）
- ステータスが「下書き」「予約済み」の場合は「送信実行」ボタンを表示

受信者ごとの配信ステータスは以下の値を取ります。

| ステータス  | 表示名       |
| ----------- | ------------ |
| `pending`   | 待機中       |
| `sent`      | 送信済み     |
| `delivered` | 配信成功     |
| `bounced`   | バウンス     |
| `opened`    | 開封済み     |
| `clicked`   | クリック済み |
| `failed`    | 失敗         |

### 配信チャネルと配信基盤

| チャネル | 表示名       | 現状                                                              |
| -------- | ------------ | ----------------------------------------------------------------- |
| `in_app` | アプリ内通知 | **実動**。受信者へアプリ内通知（Notification）を生成              |
| `email`  | メール       | **実送信は未実装**（送信処理はモック段階。Resend 連携で実装予定） |
| `line`   | LINE         | **実送信は未実装**（LINE Messaging API 連携で実装予定）           |

各チャネルの配信時には、受信者の **通知設定（NotificationPreference）** が尊重されます。

- **アプリ内**: 該当通知種別のアプリ内通知を無効化しているユーザーを除外して配信します
- **メール**: メール通知を無効化しているユーザー、および配信停止リストに登録されたアドレスを除外します（ただし現状は実送信されず、送信記録のみ）
- **LINE**: LINE 通知を明示的に有効化しているユーザーのみが対象です（既定は無効。現状は実送信されません）

### テンプレート

配信の定型文を再利用するための仕組みです。

- テンプレートには「名前」「カテゴリ（イベント / 一般）」「件名テンプレート」「HTML 本文テンプレート」「テキスト本文テンプレート」「利用可能な変数一覧」を設定できます
- 配信作成画面でテンプレートを選択すると、件名・本文が自動的に読み込まれます（読み込み後の編集も可能）
- テンプレートの作成・編集・削除は API として提供されていますが、**現状は専用の管理画面 UI が未提供** です（配信作成画面では選択・利用のみ可能）

### 配信停止リスト（サプレッション）

メール配信を行わないアドレスを管理する仕組みです。

- 登録項目: メールアドレス・停止理由（`unsubscribe` 配信停止 / `bounce` バウンス / `complaint` 苦情 / `manual` 手動）
- 配信停止リストに登録されたアドレスは、メールチャネルの配信対象から除外されます
- 追加・解除は API として提供されていますが、**現状は専用の管理画面 UI が未提供** です

## 連携・自動処理

#### 送信時のオーケストレーション

送信を実行すると、以下が自動的に行われます。

1. 配信対象種別・対象条件から受信者（ユーザー・メールアドレス）を解決
2. ステータスを「送信中」に更新し、対象者数を記録
3. 指定チャネルごとにディスパッチャを実行（各チャネルで通知設定・配信停止を尊重）
4. アプリ内チャネルでは、受信者へ通知（Notification）を一括生成
5. 送信結果（送信数・失敗数・LINE 送信数）を集計し、ステータスを「送信済み」に更新

#### 通知機能との連携

- アプリ内配信により生成された通知は、受信者の通知ベル・通知一覧に表示され、ホーム画面の「お知らせウィジェット」にも未読分が抜粋表示されます
- 通知の参照先は、全体配信ではお知らせ配信（broadcast）、イベント配信では当該イベントに設定されます

#### 本文のサニタイズ

- HTML 本文は保存時に `sanitizeRichText()` によりサニタイズされ、危険なタグ・属性が除去されます
- 配信詳細画面での HTML 本文の描画は `<SafeHtml>` を通じて安全に行われます

---

## データの取り扱い

- **配信記録の保持**: 配信（Broadcast）および受信者記録（BroadcastRecipient）はデータベースに保持され、送信状況の追跡に利用されます
- **受信者記録の一意性**: 受信者記録は「配信 × ユーザー × チャネル」の組み合わせで一意に管理されます
- **連動削除**: 配信を削除した場合、配下の受信者記録・添付ファイルも連動して削除されます（現状、配信自体の削除操作は UI では提供していません）
- **配信停止アドレスの一意性**: 配信停止リストのメールアドレスは重複登録できません

## ご利用にあたっての留意事項

- **本機能はシステム管理者・オーナーのみが利用できます**。一般ユーザーのメニューには表示されません
- **メール・LINE 配信は現時点では実際には送信されません**。配信作成画面でもこれらのチャネルは選択できず、有効なのはアプリ内通知のみです（外部配信基盤の連携は今後のフェーズで実装予定）
- 配信作成画面では **作成と送信が一括** で実行されます。作成のみ（下書き保存）を行う専用フローは現状の画面には用意されていません
- **配信予定日時（scheduledAt）** はデータとして保持できますが、予定日時になったら自動送信するバッチ処理は現状ありません。送信は管理者による手動実行です
- テンプレートの作成・編集・削除、および配信停止リストの管理は、バックエンド API としては提供済みですが、専用の管理画面 UI は現状未提供です
- 配信対象は、全体配信＝全員、イベント配信＝申込者全員（キャンセル除く）で固定です。ランク指定・カスタム指定・イベント参加ステータスによる絞り込みは今後の拡張予定です
- 受信者一覧の表示は 1 配信あたり最大 200 件です
