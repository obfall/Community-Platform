# 通知

## 概要

コミュニティ内で発生したご自身に関わる出来事を、一箇所でお受け取り・ご確認いただける機能です。イベントの申込・スキル予約・ショップ取引・チャット・アンケート・管理者からのお知らせなど、各機能で起きた出来事が「通知」としてまとめて届きます。画面右上の通知ベルに未読の有無が表示され、通知一覧ページで内容の確認・既読化・該当ページへの移動を行っていただけます。

表示される通知はすべて **ログイン中のご本人宛て** のものに限定されます。なお、管理者が全体・対象者へお知らせを送る「お知らせ配信」の操作については、別途「お知らせ配信」機能仕様書をご参照ください（本仕様書は通知を **受け取る側** の仕様を記載します）。

---

## 機能と権限

通知は **ご本人宛ての情報を確認する機能** です。一般ユーザー・システム管理者・オーナーのいずれのユーザーも、同一の通知機能をご利用いただけます（権限による機能差はございません）。

本仕様書における「操作可否」は、**ご本人が自身宛ての通知に対して** 行える操作を示します。

#### 通知の閲覧・操作

| 操作                                     | 可否 | 備考                                                     |
| ---------------------------------------- | :--: | -------------------------------------------------------- |
| 通知一覧の閲覧                           |  ○   | ご自身宛ての通知のみ                                     |
| 未読件数（ベル）の確認                   |  ○   | ヘッダーの通知ベルに未読の有無を表示                     |
| 未読のみ絞り込み                         |  ○   | 一覧上部のスイッチで切替（初期表示は未読のみ）           |
| 通知タイプによる絞り込み                 |  △   | API 対応。現状は「お知らせウィジェット」で内部利用       |
| 通知を既読にする（個別）                 |  ○   | 通知をクリックすると自動的に既読化                       |
| 全通知を一括既読にする                   |  △   | API は提供済み。現状の画面 UI からは操作不可（留意事項） |
| 関連ページへの移動                       |  ○   | 通知の種別に応じて該当ページへ遷移（詳細仕様参照）       |
| 通知チャネル設定（メール/アプリ内/LINE） |  △   | API は提供済み。現状の画面 UI からは操作不可（留意事項） |

※ 通知の削除機能は提供しておりません（既読化のみ）。

## 制限値

| 項目                           | 値                                       |
| ------------------------------ | ---------------------------------------- |
| 通知タイトル                   | 最大 200 文字                            |
| 通知種別（type）               | 最大 30 文字（内部識別子）               |
| 一覧の 1 ページあたり表示件数  | 20 件（初期値）                          |
| 1 ページあたりの最大取得件数   | 100 件                                   |
| 未読数バッジの自動更新間隔     | 60 秒ごと                                |
| お知らせウィジェットの取得件数 | 最大 100 件（うち折りたたみ時 3 件表示） |

※ 通知本文（body）の文字数上限は設定しておりません。

## 詳細仕様

### 通知の届く場所

通知は 3 つの場所でご確認いただけます。

| 場所                               | 内容                                                                            |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| ヘッダーの通知ベル                 | 未読が 1 件以上ある場合、ベルアイコンに赤い印を表示（件数の数字は表示しません） |
| 通知一覧ページ（`/notifications`） | すべての通知を新しい順に一覧表示。既読化・絞り込み・該当ページへの移動が可能    |
| ホーム画面のお知らせウィジェット   | 管理者からのお知らせ（announcement / event_announcement）の未読のみを抜粋表示   |

- 通知ベルの未読表示は **約 60 秒ごとに自動更新** されます（バッジ表示のため、反映に多少の遅延が生じる場合があります）
- 未読バッジは「未読が存在するか否か」を示す赤い印であり、具体的な未読件数の数字は表示いたしません

### 通知一覧ページ

- 通知は **作成日時の新しい順** に表示されます
- 各通知には、送信者（アクター）のアバター・タイトル・本文（任意）・相対時刻（「〇分前」等）が表示されます
- **未読の通知** は強調表示（背景色・太字・右端の丸印）され、**既読の通知** は淡色表示されます
- 画面上部のスイッチで「未読のみ表示」を切り替えられます（**初期表示は未読のみ**）
- 1 ページ 20 件で、ページネーションバーによりページを切り替えられます
- 通知が 1 件もない場合は「通知はありません」と表示されます

### 既読化と画面遷移

通知をクリックすると、以下が同時に行われます。

1. 未読の場合は **自動的に既読** となります（既読日時を記録）
2. 通知の種別（referenceType）に応じて、関連ページへ遷移します

| 通知の参照先（referenceType） | 遷移先                                       |
| ----------------------------- | -------------------------------------------- |
| チャットルーム（chat_room）   | チャット画面（`/chat`）                      |
| 掲示板投稿（board_post）      | 掲示板の該当投稿（`/board/:id`）             |
| アンケート（survey）          | アンケート回答画面（`/surveys/:id/respond`） |
| ショップ注文（shop_order）    | 注文詳細（`/shop/orders/:id`）               |
| スキル予約（skill_booking）   | スキル予約詳細（`/skills/bookings/:id`）     |

- 上記以外の参照先（イベント・動画・お知らせ配信など）を持つ通知は、クリック時に **既読化のみ** 行われ、ページ遷移は発生しません
- 参照先が設定されていない通知も、既読化のみ行われます

### 通知の種類（type）

通知は発生源となる機能ごとに種別が分かれています。現在システムが生成する通知は以下のとおりです。

#### 管理者からのお知らせ（お知らせ配信 経由）

| 種別（type）         | 内容                           | 参照先       |
| -------------------- | ------------------------------ | ------------ |
| `announcement`       | 全体・対象者向けの一般お知らせ | お知らせ配信 |
| `event_announcement` | イベントに紐づくお知らせ       | イベント     |

#### イベント

| 種別（type）                 | 契機                                     | 受信者         |
| ---------------------------- | ---------------------------------------- | -------------- |
| `event_application`          | イベント申込の完了                       | 申込者ご本人   |
| `event_application_received` | 新しいイベント申込の受信                 | 主催者・管理者 |
| `event_capacity_reached`     | イベントが定員に達した                   | イベント作成者 |
| `event_remaining_threshold`  | 残席が規定数を下回った                   | イベント作成者 |
| `event_reminder`             | 開催前のイベントリマインダー（自動配信） | 参加者         |

#### スキル予約

| 種別（type）              | 契機                       | 受信者       |
| ------------------------- | -------------------------- | ------------ |
| `skill_booking_requested` | 新しい予約リクエスト       | スキル提供者 |
| `skill_booking_approved`  | 予約が承認された           | リクエスト者 |
| `skill_booking_rejected`  | 予約が拒否された           | 相手方       |
| `skill_booking_canceled`  | 予約がキャンセルされた     | 相手方       |
| `skill_booking_completed` | 予約が完了した             | 相手方       |
| `skill_message`           | スキル取引に新着メッセージ | 相手方       |

#### ショップ取引

| 種別（type）             | 契機                   | 受信者 |
| ------------------------ | ---------------------- | ------ |
| `shop_order_requested`   | 商品の購入申込         | 出品者 |
| `shop_order_negotiating` | 取引が開始された       | 購入者 |
| `shop_order_completed`   | 取引が完了した         | 相手方 |
| `shop_order_canceled`    | 注文がキャンセルされた | 相手方 |

#### その他

| 種別（type）          | 契機                             | 受信者         |
| --------------------- | -------------------------------- | -------------- |
| `chat_message`        | チャットの新着メッセージ         | ルームメンバー |
| `survey`              | アンケートの配信・回答リマインド | 対象メンバー   |
| `video_task_reminder` | 動画の未完了タスクのリマインダー | タスク担当者   |

### 通知チャネルと設定

通知には 3 つの配信チャネルが定義されており、通知種別ごとにチャネルの ON/OFF を保持できる仕組み（通知設定）が用意されています。

| チャネル           | 既定値 | 現状                                                                           |
| ------------------ | :----: | ------------------------------------------------------------------------------ |
| アプリ内（in-app） |   ON   | 実動。通知一覧・通知ベルに表示される通知はこのチャネルです                     |
| メール（email）    |   ON   | **現状は実送信されません**（送信処理はモック段階。将来 Resend 連携で実装予定） |
| LINE               |  OFF   | **現状は実送信されません**（LINE Messaging API 連携は将来実装予定）            |

- 通知設定は「通知種別 × チャネル」単位で保持されます（未設定の種別は上表の既定値として扱われます）
- 通知チャネル設定を参照するのは **お知らせ配信（broadcast）経由の通知のみ** です。各機能の出来事から直接発生する通知（イベント申込・スキル予約・チャット等）は、設定に関わらず必ずアプリ内通知として作成されます
- 通知設定の取得・更新 API は提供済みですが、**現状の画面 UI からは設定操作を行えません**（今後実装予定）

## 連携・自動処理

#### 各機能からの自動生成

- 通知は、各機能（イベント・スキル・ショップ・チャット・アンケート・動画・お知らせ配信）で特定の出来事が発生した際に **自動的に生成** されます。ユーザーが手動で通知を作成することはありません
- 各機能側の通知生成は、メイン処理の成否に影響しないよう **非同期・失敗許容** で行われます（通知作成に失敗しても、申込・予約などの本処理は正常に完了します）

#### お知らせ配信との連携

- 管理者による「お知らせ配信」が実行されると、対象ユーザーへアプリ内通知（`announcement` / `event_announcement`）が一括生成されます
- ホーム画面の「お知らせウィジェット」は、これらの未読お知らせを最大 100 件取得し、初期状態で 3 件、「もっと見る」で全件を表示します

#### イベントリマインダーの自動配信

- 開催前のイベントについて、バックグラウンド処理により参加者へ `event_reminder` 通知が自動配信されます

## データの取り扱い

- **保持**: 通知は削除されず、既読化後もデータベース上に保持されます。既読化の際は「既読フラグ」と「既読日時」を記録します
- **未読数の集計**: 通知ベルの表示は、未読通知の件数を軽量に集計して判定しています（高頻度のポーリングに耐えるため、この集計はレートリミットの対象外としています）
- **公開範囲**: 通知はすべて宛先ユーザーご本人のみが閲覧できます。他ユーザーの通知を閲覧することはできません
- **本人確認**: 通知の既読化は、対象通知が自分宛てであることを確認したうえで実行されます（他ユーザー宛て通知を既読化しようとした場合は「見つかりません」となります）
- **ユーザー削除時**: ユーザーが削除された場合、その宛先通知も連動して削除されます。送信者（アクター）が削除された場合、通知自体は残り、送信者情報のみ空になります

## ご利用にあたっての留意事項

- **メール通知・LINE 通知は現時点では実際には送信されません**。配信基盤の連携は今後のフェーズで実装予定で、現状はアプリ内通知（通知ベル・通知一覧）のみが有効です
- 通知チャネルの ON/OFF を設定する画面 UI は現状提供しておりません（設定の仕組み自体はバックエンドに用意されています）
- 「すべて既読にする」一括既読化は API として用意されていますが、現状の画面からは操作いただけません。既読化は通知を個別にクリックすることで行ってください
- 通知そのものを削除する機能は提供しておりません（既読化のみ可能です）
- 通知ベルの未読表示は最大約 60 秒の更新間隔があるため、新着通知が反映されるまで多少の時間差が生じる場合があります
- 通知機能はシステム設定により機能全体の有効・無効を切り替えられる場合があります。無効化されている環境では通知の取得・表示は行われません
- 掲示板・プロジェクト・メモなど、一部の機能では現時点で通知を生成していません（対象機能は「通知の種類」の一覧に記載のものに限られます）
