# マイページ

## 概要

ログイン中のご自身専用のパーソナルスペースです。プロフィール（基本情報・公開情報・自己申告属性）の管理を中心に、活動履歴・ポイント・マイライブラリー・マイチケット・マイ予約・マイタスク・マイカレンダー・メモ・各種設定を一箇所からご利用いただけます。左側のサイドバーから各機能へ切り替えていただく構成となっており、表示されるデータはすべて **ログイン中のご本人のもの** に限定されます。

---

## 機能と権限

マイページは **ご本人専用のページ** です。一般ユーザー・システム管理者・オーナーのいずれのユーザーも、同一のマイページ機能をご利用いただけます（権限による機能差はございません。他ユーザーの管理はマイページとは別の管理者用画面にて行います）。

本仕様書における「操作可否」は、原則として **ご本人が自身のデータに対して** 行える操作を示します。

#### プロフィール

| 操作                                     | 可否 | 備考                                             |
| ---------------------------------------- | :--: | ------------------------------------------------ |
| プロフィール（基本情報・公開情報）の閲覧 |  ○   | 自身の情報のみ                                   |

| 公開情報の編集                           |  ○   | ニックネーム・活動拠点・専門分野・自己紹介など   |

| 操作                     | 可否 | 備考                               |

| パスワードの変更         |  ○   | 現在のパスワードによる本人確認あり |

## 詳細仕様

### プロフィール

#### 表示構成

プロフィールトップ画面では、以下の 4 区分を上から順に表示いたします。

1. **基本情報（ヒーロー）**: アバター・ヘッダー画像・氏名・ロール・メールアドレス・保有ポイント・参加日
2. **プロフィール情報**: 名前（カナ）・職業・電話番号・生年月日・性別・出身国・所属
3. **公開情報**: ニックネーム・公開ステータス・活動拠点・専門分野・イベント役割・自己紹介・興味分野
4. **自己申告属性**: 管理者が定義した属性のうち、本人編集が許可されたもの

各区分の「編集」ボタンより、それぞれの編集画面へ遷移いたします。

#### 基本プロフィールの編集項目

| 項目           | 形式             | 制限・選択肢                                                     |
| -------------- | ---------------- | ---------------------------------------------------------------- |
| アバター画像   | 画像アップロード | 最大 5 MB、画像ファイルのみ                                      |
| ヘッダー画像   | 画像アップロード | 最大 10 MB、画像ファイルのみ                                     |
| メールアドレス | 表示のみ         | 変更は「設定」画面にて（本編集画面では読み取り専用）             |
| 名前（カナ）   | テキスト         | 最大 100 文字、全角カタカナ・長音符・スペースのみ                |
| 電話番号       | テキスト         | ハイフンなし半角数字 10〜11 桁                                   |
| 生年月日       | 日付             |                                                                  |
| 性別           | セレクト         | 男性／女性／その他／回答しない                                   |
| 職業           | ラジオボタン     | 会社員／学生／自営業／主婦・主夫／無職／その他                   |
| 出身国         | テキスト         | 最大 100 文字                                                    |
| 所属           | 複数登録         | 組織名・部署・肩書を 1 セットとして複数登録可（各 200 文字以内） |

- 名前（カナ）は全角カタカナのみ受け付けます（半角カナ・ひらがな・漢字は入力できません）
- 電話番号はハイフンを含まない半角数字での入力をお願いいたします
- 所属は「＋」ボタンで追加、「×」ボタンで削除いただけます

#### 公開情報の編集項目

| 項目                 | 形式                 | 制限・選択肢                                        |
| -------------------- | -------------------- | --------------------------------------------------- |
| 公開ステータス       | トグルスイッチ       | 公開／非公開（初期値: 非公開）                      |
| ニックネーム         | テキスト             | 最大 100 文字                                       |
| ニックネーム（カナ） | テキスト             | 最大 100 文字、全角カタカナ・長音符・スペースのみ   |
| 活動拠点（都道府県） | セレクト             | 47 都道府県から選択                                 |
| 活動拠点（市区町村） | テキスト             | 最大 100 文字                                       |
| 専門分野             | 階層チェックボックス | 分野カテゴリから複数選択（親カテゴリで一括選択可）  |
| イベント役割         | チェックボックス     | 講師／司会／通訳／企画／登壇者／出演者 から複数選択 |
| 自己紹介             | テキストエリア       | 文字数上限なし、改行を保持して表示                  |
| 興味分野             | チェックボックス     | カテゴリ一覧から複数選択（最大 50 件）              |

- **公開ステータス** が「公開」の場合、公開情報は他ユーザーのプロフィール閲覧時にも表示されます。「非公開」の場合、他ユーザーには表示されません（ご本人のマイページには常に表示されます）
- 基本プロフィール（名前カナ・電話番号・生年月日・性別・職業・出身国・所属）は公開ステータスに関わらず **ご本人のみ** が閲覧できる情報です
- 専門分野の選択肢は、IT・テクノロジー／ビジネス／デザイン／教育／スポーツ／音楽・芸術／医療・健康／法律・政治／科学・研究／ものづくり などのカテゴリで構成されています

#### 自己申告属性

- コミュニティ管理者が定義した「メンバー属性」のうち、**本人による編集が許可された属性のみ** が表示・編集対象となります
- 属性の種類に応じて入力欄が自動的に切り替わります。

| 属性タイプ   | 入力方式         | 表示形式                     |
| ------------ | ---------------- | ---------------------------- |
| テキスト     | テキスト入力     | そのまま表示                 |
| 数値         | 数値入力         | そのまま表示                 |
| 日付         | 日付入力         | 「YYYY年MM月DD日」形式で表示 |
| 選択（単一） | セレクト         | 選択したラベルを表示         |
| 選択（複数） | チェックボックス | バッジで複数表示             |

### 活動履歴

- 参加した **イベント** と **プロジェクト** の件数サマリー、および一覧を表示いたします
- 各項目をクリックすると、当該イベント／プロジェクトの詳細ページへ遷移いたします
- ステータス（募集中・終了・中止など）はバッジにて表示されます
- 本画面はページング非対応（参加分を全件表示）です

### ポイント

- **現在「準備中」表示となっております。** ポイント機能は仕様が未確定のため、残高・履歴の表示は一時的に無効化しております
- 将来的には「利用可能ポイント」「付与ポイント合計」「利用ポイント合計」およびポイント履歴（20 件単位）の表示を予定しています
- なお、サイドバー上部およびプロフィールトップには現在の保有ポイント数のみ表示されます

### マイライブラリー

- 読書記録・資料などを個人的に登録・管理いただく機能です
- 登録項目: 種別（本／雑誌／マンガ／論文／書類／その他）・タイトル・内容・著者・出版日・ページ数・所感・ステータス・添付ファイル
- ステータス: 未読／読書中／完読／欲しい／貸出中
- 各項目の三点リーダーメニューより「編集」「削除」をお選びいただけます
- 添付ファイルは **1 件のみ** 登録可能です（差し替え・解除が可能）
- 本画面はページング非対応（全件表示）です

### マイチケット

- 申し込んだ **イベント参加チケット** を一覧表示いたします
- ステータスによる絞り込み（すべて／応募中／参加／不参加）に対応しています
- 「もっと見る」ボタンによる追加読み込み（1 回 20 件）に対応しています
- 各チケットをクリックすると、詳細ダイアログ（イベント名・日時・会場／オンライン URL・チケット名・価格・数量・支払いステータス・申込日時・イベント詳細へのリンク）が表示されます
- ステータスが「応募中」または「確定」のチケットは、**キャンセル** が可能です（確認ダイアログのうえ実行）
- キャンセル済みのチケットは一覧に表示されません

### マイ予約

- **会場予約** と **スキル予約** をまとめて一覧表示いたします
- 会場予約はステータスによる絞り込み（すべて／保留中／確認済み）に対応しています
- 「もっと見る」ボタンによる追加読み込み（1 回 20 件）に対応しています
- 各予約をクリックすると、詳細ダイアログ（会場名・日時・時間帯・メモ・作成日時など）が表示されます
- ステータスが「保留中」「確認済み」「承認済み」の予約は、**キャンセル** が可能です（確認ダイアログのうえ実行）
- スキル予約は「承認済み」のもののみ表示され、スキル内容・相手方・予定日時・価格・所要時間を確認いただけます
- キャンセル済みの予約は一覧に表示されません

### マイタスク

- 参加プロジェクトにおいて **ご自身に割り当てられたタスク** を一覧表示いたします
- ステータスによる絞り込み（すべて／未着手／進行中／完了）に対応しています
- 「もっと見る」ボタンによる追加読み込み（1 回 20 件）に対応しています
- 完了済みのタスクはタイトルに取り消し線が表示されます
- 各タスクをクリックすると、詳細ダイアログ（タイトル・プロジェクト名・依頼日・期限・説明）が表示されます
- タスクの一覧はステータス順（未着手→進行中→完了）、同一ステータス内では作成日の新しい順に表示されます
- タスクの作成・編集は各プロジェクト内で行います（マイタスクは閲覧が中心です）

### マイカレンダー

- 月別カレンダーに、複数種別の予定を **色分けにて重畳表示** いたします。種別ごとに表示／非表示を切り替えられます。

| 種別                     | 色       | 内容                                 |
| ------------------------ | -------- | ------------------------------------ |
| 個人予定（本人が作成）   | 青       | マイカレンダーで作成した予定         |
| 会場予約・スキル予約     | 緑       | 予定日時が設定された予約             |
| 担当タスク（期限付き）   | オレンジ | 期限日を終日予定として表示           |
| イベントチケット         | グレー   | 参加イベント（キャンセル済みを除く） |
| プロジェクトスケジュール | 紫       | 参加プロジェクト内のスケジュール     |

- 個人予定の作成項目: タイトル（必須）・説明・開始日時（必須）・終了日時（必須）・終日フラグ・場所
- 予定は作成後に編集・削除いただけます
- 予定保存後は自動的にダイアログを閉じ、カレンダー表示に戻ります

### メモ

- ご自身専用のメモを作成・閲覧・編集・削除いただく機能です
- 一覧ではタイトル検索・カテゴリによる絞り込みが可能です
- カテゴリはご自身で作成・選択いただけます
- 本文は **プレーンテキスト** で入力し、改行・空白はそのまま保持して表示されます（装飾・マークダウン記法には対応しておりません）
- 添付ファイルの管理に対応しています
- メモ詳細画面の三点リーダーメニューより「編集」「削除」をお選びいただけます（削除時は確認のうえ実行）
- メモは **ご本人のみ** が閲覧できます

### 設定

- 登録中のメールアドレスを表示いたします（本画面では変更いただけません）
- パスワードの変更が可能です。「現在のパスワード」による本人確認のうえ、「新しいパスワード」（8 文字以上）と「確認用パスワード」の一致を確認して変更いたします
- パスワード変更の完了後は、プロフィールトップ画面へ遷移いたします

## 連携・自動処理

#### キャンセルに伴う自動更新

- チケットをキャンセルされた場合、該当チケットの販売数およびイベントの参加者数が自動的に減算されます
- キャンセルされたチケット・予約は、各一覧から自動的に除外されます

#### カレンダーへの自動反映

- 会場予約・スキル予約・担当タスクの期限・参加イベント・プロジェクトスケジュールは、マイカレンダーへ自動的に反映されます（個別の登録操作は不要です）

#### プロフィール更新時の一括置換

- 所属・興味分野は、更新時に既存の登録内容を全件置き換える方式で保存されます

## データの取り扱い

- **論理削除**: メモ・カレンダー予定は削除しても画面上で非表示となるのみで、データベース上には保持されます
- **物理削除**: マイライブラリーの項目は削除時にデータそのものが削除されます
- **キャンセルの記録**: チケット・予約のキャンセルはステータスを「キャンセル済み」に変更し、キャンセル日時を記録します（データは保持されます）
- **公開範囲**: 基本プロフィール・自己申告属性・メモ・マイライブラリー等の個人データは、原則としてご本人のみが閲覧できます。他ユーザーへ公開されるのは、公開ステータスを「公開」に設定した場合の「公開情報」に限られます

---

## ご利用にあたっての留意事項

- ポイント機能は現在「準備中」です。残高・履歴の表示は仕様確定後に有効化いたします
- キャンセルされたチケット・予約は、画面上から復元することはできません
- マイライブラリーの添付ファイルは 1 項目につき 1 件までとなります
- メモ本文はプレーンテキストのみに対応しており、文字装飾・URL の自動リンク化には対応しておりません
- マイタスクは閲覧を中心とした画面です。タスクの作成・担当割当・ステータス変更などの操作は各プロジェクトの画面にて行います
- パスワードの変更にはお手元の「現在のパスワード」が必要です。お忘れの場合は管理者による強制リセットが必要となります
