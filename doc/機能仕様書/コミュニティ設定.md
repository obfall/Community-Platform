# コミュニティ設定

## 概要

コミュニティ全体の見た目・振る舞いを管理者が一元管理する機能です。設定画面（`/settings/community`）は 4 つのタブで構成され、それぞれ **基本設定・デザイン・メール・カスタム属性** を扱います。

- **基本設定**: サイト名・サイト説明・新規登録の可否
- **デザイン**: ファビコン・配色（プライマリー/アクセント/ヘッダー/サイドバー）・フォント
- **メール**: 送信元情報・メンバー登録完了メールの件名/本文テンプレート
- **カスタム属性**: メンバーに付与するコミュニティ独自の項目定義

基本設定・デザイン・メールの各値は「アプリ設定（app_settings）」として **キー・値のペア** で保持され、値はすべて文字列として保存されます。カスタム属性は独立した「メンバー属性定義（member_attributes）」として保持されます。

---

## 機能と権限

コミュニティ設定は **コミュニティ運営に関わる管理機能** です。設定の変更はシステム管理者・オーナーに限定されます。

| 操作                                     | 一般ユーザー | システム管理者 | オーナー | 備考                                        |
| ---------------------------------------- | :----------: | :------------: | :------: | ------------------------------------------- |
| コミュニティ設定画面を開く               |      ×       |       ○        |    ○     | 設定メニューは管理者のみ表示                |
| アプリ設定の閲覧（基本/デザイン/メール） |      ○       |       ○        |    ○     | 設定取得 API は公開（ログイン前でも参照可） |
| アプリ設定の更新                         |      ×       |       ○        |    ○     | `admin` / `owner` ロールのみ                |
| カスタム属性定義の閲覧                   |      ○       |       ○        |    ○     | ログイン済みユーザーが参照可                |
| カスタム属性定義の作成・更新・削除       |      ×       |       ○        |    ○     | `admin` / `owner` ロールのみ                |
| 属性の並び替え                           |      ×       |       ○        |    ○     | `admin` / `owner` ロールのみ                |
| メンバー CSV エクスポート                |      ×       |       ○        |    ○     | 全メンバー＋属性値を CSV 出力               |

- アプリ設定の **取得** API は認証不要（公開）です。ログイン前のページ（登録画面・全体テーマ適用）が設定値を読み取れるようにするためです
- アプリ設定の **更新** と、カスタム属性のすべての **書き込み** 操作は `admin` / `owner` に限定されます

---

## 制限値

| 項目                             | 値                                              |
| -------------------------------- | ----------------------------------------------- |
| アプリ設定の値（value）          | 文字数上限なし（文字列として保存）              |
| カスタム属性名（name）           | 最大 100 文字                                   |
| カスタム属性スラッグ（slug）     | 最大 100 文字・英小文字/数字/アンダースコアのみ |
| ファビコン画像                   | 最大 5MB・画像ファイルのみ（推奨 32×32 以上）   |
| アプリ設定のキャッシュ保持       | 60 分（更新時に自動失効）                       |
| カスタム属性定義のキャッシュ保持 | 60 分（作成・更新・削除・並び替え時に自動失効） |

- 設定値はすべて文字列として保存され、真偽値（`allow_registration` 等）は `"true"` / `"false"` の文字列で表現されます

## 詳細仕様

### タブ 1: 基本設定

コミュニティの基本情報を設定します。

| 項目           | キー                 | 型     | 初期値               | 内容                                                                               |
| -------------- | -------------------- | ------ | -------------------- | ---------------------------------------------------------------------------------- |
| サイト名       | `site_name`          | 文字列 | `Community Platform` | コミュニティの表示名。必須                                                         |
| サイト説明     | `site_description`   | 文字列 | （初期値あり）       | Google 検索結果や SNS シェア時に表示される説明文。画面上には直接表示されない。必須 |
| 新規登録を許可 | `allow_registration` | 真偽値 | `true`               | 無効にすると新規ユーザーが登録できなくなる                                         |

- サイト名・サイト説明は空欄では保存できません（バリデーションエラー）
- **新規登録の可否はフロント・バックエンドの両方で作用します**。無効時は登録画面が申込を受け付けず、登録 API 側でも `RegistrationAllowedGuard` により拒否されます

### タブ 2: デザイン

サイトのロゴ・配色・フォントをカスタマイズします。設定値は全ユーザーの画面に即時反映されます（ダークモードは非対応）。

| 項目                   | キー                   | 内容                                                            |
| ---------------------- | ---------------------- | --------------------------------------------------------------- |
| ファビコン             | `favicon_url`          | ブラウザタブに表示されるアイコン。画像アップロードで設定        |
| プライマリーカラー     | `primary_color`        | ボタン・バッジ・リンクなど主要アクションのメインカラー          |
| アクセントカラー       | `accent_color`         | hover / 選択時に表示されるハイライト色                          |
| ヘッダー背景色         | `header_bg_color`      | サイト名（ロゴ）の背景色。空欄でデフォルト                      |
| ロゴ文字色             | `header_text_color`    | サイト名の文字色。空欄時はヘッダー背景から自動計算              |
| サイドバー背景色       | `sidebar_bg_color`     | 文字色は背景色から自動計算                                      |
| サイドバー選択時背景色 | `sidebar_accent_color` | サイドバー項目の hover / 選択時のハイライト色                   |
| フォント               | `font_family`          | デフォルト（システム）／ Noto Sans JP ／ Noto Serif JP から選択 |

- 配色はカラーピッカーまたは HEX 値の直接入力で指定できます
- **文字色（foreground）は背景色の明度から自動計算** されます（背景が暗ければ白文字、明るければ黒文字）。ロゴ文字色のみ明示指定が可能です
- 画面下部に **プレビューパネル** があり、保存前に配色・フォントの見え方を確認できます
- 「初期化」ボタンで全デザイン設定をデフォルトに戻せます（確認ダイアログあり）。プライマリー/アクセントは既定色に、その他は空欄に戻ります
- デザイン値は `ThemeApplier` により CSS 変数・`<body>` スタイル・`<link rel="icon">` に動的適用されます。空欄の項目は CSS 変数を削除し `globals.css` の既定に戻します

### タブ 3: メール

メール送信時の差出人情報と、メンバー登録完了メールの内容を設定します。

| 項目               | キー                    | 内容                                           |
| ------------------ | ----------------------- | ---------------------------------------------- |
| 差出人名           | `email_from_name`       | 受信者のメールソフトに表示される送信者名。必須 |
| 返信先アドレス     | `email_reply_to`        | 受信者が返信した際の宛先。メール形式のみ許可   |
| 登録完了メール件名 | `email_welcome_subject` | メンバー登録完了メールの件名。必須             |
| 登録完了メール本文 | `email_welcome_body`    | メンバー登録完了メールの本文。必須             |

- 件名・本文では以下の **差し込み変数** を利用できます。送信時に実際の値へ置換される想定です

  | 変数            | 置換内容           |
  | --------------- | ------------------ |
  | `{{site_name}}` | サイト名           |
  | `{{user_name}}` | 登録者の名前       |
  | `{{email}}`     | 登録メールアドレス |

- 件名・本文にはそれぞれ「初期化」ボタンがあり、デフォルトのテンプレートに戻せます（保存を押すまで反映されません）
- 返信先アドレスはメール形式のバリデーションが行われます

### タブ 4: カスタム属性

メンバーに割り当てるコミュニティ独自の項目（属性定義）を管理します。

#### 属性の型（type）

| 型             | 内容     | 選択肢（options） |
| -------------- | -------- | :---------------: |
| `text`         | テキスト |         −         |
| `number`       | 数値     |         −         |
| `date`         | 日付     |         −         |
| `select`       | 単一選択 |       必須        |
| `multi_select` | 複数選択 |       必須        |

- `select` / `multi_select` は選択肢（options）が **1 件以上必須** です。UI ではカンマ区切りで入力します
- **属性の型（type）とスラッグ（slug）は作成後に変更できません**。編集時はタイプ欄が表示されず、名前・選択肢・編集権限のみ変更可能です

#### 属性の設定項目

| 項目       | 内容                                                                |
| ---------- | ------------------------------------------------------------------- |
| 属性名     | 表示名（最大 100 文字）                                             |
| スラッグ   | 識別子。指定省略時は `attr_{連番}` で自動採番（欠番は再利用しない） |
| 編集権限   | 「メンバー自身も編集可（`isSelfEditable`）」か「運営のみ」か        |
| 必須フラグ | `isRequired`。必須属性は空値で保存できない                          |
| 表示順     | `sortOrder`。並び替えで調整                                         |

- 一覧はテーブル形式で、属性名・タイプ・編集権限・選択肢を表示します
- 属性を **削除すると、全メンバーのその属性値も連動して削除** されます（確認ダイアログあり）

#### メンバー属性値の入力・参照

属性定義に対する各メンバーの値は、別の経路で入出力されます。

| 操作                       | エンドポイント                | 権限          | 備考                                            |
| -------------------------- | ----------------------------- | ------------- | ----------------------------------------------- |
| 自分の属性値を参照         | `GET /users/me/attributes`    | 本人          | **メンバー編集可の属性のみ** 返却               |
| 自分の属性値を更新         | `PATCH /users/me/attributes`  | 本人          | `isSelfEditable=true` の属性のみ更新可          |
| 特定メンバーの属性値を参照 | `GET /users/:id/attributes`   | admin / owner | 管理者専用属性を含む全属性                      |
| 特定メンバーの属性値を設定 | `PATCH /users/:id/attributes` | admin / owner | 一括 upsert（値 `null` で削除）                 |
| メンバー CSV エクスポート  | `GET /users/export/csv`       | admin / owner | 固定列＋全カスタム属性列を UTF-8 BOM 付きで出力 |

- **メンバー本人による更新** は `isSelfEditable=true` の属性に限定され、運営のみの属性を本人が更新しようとするとエラーになります
- 必須属性を空値で設定しようとした場合はエラーになります

## API 一覧

### アプリ設定（基本 / デザイン / メール共通）

| メソッド | パス                 | 権限          | 内容                   |
| -------- | -------------------- | ------------- | ---------------------- |
| `GET`    | `/settings/app`      | 公開          | アプリ設定一覧取得     |
| `PATCH`  | `/settings/app/:key` | admin / owner | 設定値をキー単位で更新 |

- 画面の各フォームは、変更のあったキーのみを個別に `PATCH` します（複数キーを並列送信し、一部失敗時は「N 件の保存に失敗」と通知）

### カスタム属性定義

| メソッド | パス                         | 権限          | 内容         |
| -------- | ---------------------------- | ------------- | ------------ |
| `GET`    | `/member-attributes`         | 認証          | 属性定義一覧 |
| `POST`   | `/member-attributes`         | admin / owner | 属性定義作成 |
| `PATCH`  | `/member-attributes/reorder` | admin / owner | 並び替え     |
| `PATCH`  | `/member-attributes/:id`     | admin / owner | 属性定義更新 |
| `DELETE` | `/member-attributes/:id`     | admin / owner | 属性定義削除 |

## データの取り扱い

- **保存形式**: アプリ設定はキー・値のペアで保持され、値・型（valueType）・説明・最終更新者（`updatedByUserId`）を記録します。真偽値・色・URL もすべて文字列として保存されます
- **キャッシュ**: アプリ設定一覧・カスタム属性定義一覧はいずれも 60 分キャッシュされ、更新系操作の実行時にキャッシュを失効させます（高頻度参照に耐えるため）
- **属性値のカスケード**: カスタム属性定義を削除すると、紐づく全メンバーの属性値（`member_attribute_values`）も削除されます
- **CSV エクスポート**: 削除済みユーザーを除く全メンバーについて、固定列（名前・メール・ロール・ステータス・ランク・登録日）＋各カスタム属性の値を出力します。Excel での文字化けを防ぐため UTF-8 BOM を付与します

## 連携・自動処理

- **デザイン設定の即時反映**: `ThemeApplier` がアプリ設定を購読し、配色・フォント・ファビコンを document へ動的適用します。設定変更後、再取得のタイミングで全画面に反映されます
- **新規登録の制御**: `allow_registration` は登録画面の表示制御（フロント）と登録 API の `RegistrationAllowedGuard`（バック）の双方で参照されます
- **ヘッダー・登録画面での参照**: サイト名・ロゴ・配色などのアプリ設定は、ヘッダー・登録画面などログイン前後の各所で参照されます

## ご利用にあたっての留意事項

- **メール設定（差出人名・返信先・登録完了メール）は現時点では実送信に接続されていません**。設定値は保存されますが、バックエンドに実際の送信処理・テンプレート差し込み処理は未実装です。差し込み変数（`{{site_name}}` 等）も送信基盤の実装後に有効化される想定です
- **デザインタブに表示されない設定キーがあります**。`logo_url`（ヘッダーのロゴ画像）・`background_color`（ページ背景色）・`text_color`（本文文字色）は設定として存在し `ThemeApplier` で適用されますが、現状のデザインフォム UI からは編集できません
- **ダークモードには非対応** です。配色はライトモード前提で、背景色の明度から文字色を自動計算します
- **属性の型・スラッグは作成後に変更できません**。型を変えたい場合は削除して作り直す必要があります（既存の属性値は失われます）
- アプリ設定の取得 API は **公開（認証不要）** です。機密情報は設定値に含めない運用としてください
- 設定変更後、他ユーザーの画面へ反映されるまで、キャッシュ・再取得のタイミングにより多少の遅延が生じる場合があります
