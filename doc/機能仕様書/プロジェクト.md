# プロジェクト

## 概要

特定のメンバーで集まって活動するための、プロジェクト管理機能です。各プロジェクトには専用のメッセージ・タスク・スケジュール・掲示板・ファイル管理のスペースが用意され、参加メンバー間で活動を進めていただけます。プロジェクトには「ホスト（管理者）」を設定でき、プロジェクト単位でメンバーの追加・削除や設定変更を行っていただけます。

---

## 機能と権限

本機能における権限は、以下の 3 つの区分にてご利用いただけます。

- **一般ユーザー**: コミュニティの通常メンバー
- **プロジェクトホスト**: 各プロジェクト内で「管理者」の役割を持つメンバー（プロジェクト単位での管理権限）
- **システム管理者・オーナー**: コミュニティ全体の管理者・オーナー（全プロジェクトに対する管理権限）

## 制限値

| 項目                           | 値                                                  |
| ------------------------------ | --------------------------------------------------- |
| プロジェクト名                 | 最大 200 文字                                       |
| メッセージ（スレッド）タイトル | 最大 200 文字                                       |
| タスクタイトル                 | 最大 200 文字                                       |
| スケジュールタイトル           | 最大 200 文字                                       |
| スケジュール開催場所           | 最大 200 文字                                       |
| タグ                           | 1 プロジェクトあたり最大 5 件、各 50 文字以内       |
| 検索キーワード                 | 最大 200 文字                                       |
| 一覧の 1 ページあたり表示件数  | 12 件（プロジェクト一覧） / 20 件（メッセージ一覧） |
| カバー画像URL                  | 最大 500 文字                                       |

※ プロジェクト説明文・メッセージ返信本文・タスク説明・スケジュール詳細の文字数上限は現状設定しておりません。

## 詳細仕様

#### プロジェクトのステータス

プロジェクトには以下の 4 種類のステータスを設定いただけます。

| ステータス    | 表示名 | 用途                     |
| ------------- | ------ | ------------------------ |
| `not_started` | 開始前 | 開始前のプロジェクト     |
| `in_progress` | 進行中 | 活動中のプロジェクト     |
| `completed`   | 終了   | 完了したプロジェクト     |
| `cancelled`   | 中止   | 中止となったプロジェクト |

#### 一覧表示の範囲

ユーザー区分に応じて、一覧に表示される範囲が異なります。

- **システム管理者・オーナー**: すべてのプロジェクトを閲覧可能
- **一般ユーザー（プロジェクトホスト含む）**:
  - 「開始前」「進行中」のプロジェクトはすべて表示
  - 「終了」「中止」のプロジェクトは **ご自身が参加中のもの** のみ表示

#### プロジェクトの作成項目

プロジェクト作成時には以下の項目を設定いただけます。

- プロジェクト名（必須）
- 説明（任意、改行を保持して表示）
- カバー画像（任意、画像アップロード対応）
- ステータス（初期値: 開始前）
- 開始日・終了日（任意）
- 関連イベント（任意、コミュニティイベントから選択）
- タグ（任意、最大 5 件）

#### メンバーのロール

各プロジェクトメンバーは以下のいずれかのロールを持ちます。

| ロール             | 説明                                                         |
| ------------------ | ------------------------------------------------------------ |
| ホスト（admin）    | プロジェクトの管理権限あり（編集・削除・メンバー管理が可能） |
| メンバー（member） | 一般参加者                                                   |

- プロジェクト作成者は自動的に「ホスト」として登録されます
- メンバーのロールは、プロジェクトホスト・システム管理者により切替可能です
- プロジェクト作成者本人のロールは変更できません（誤って権限を失うことを防ぐため）

#### メッセージ（スレッド）の表示・並び順

- プロジェクト詳細の「メッセージ」タブにて、スレッド一覧を表示いたします
- 並び順は以下の優先順序にて表示されます。
  1. ピン留めされたスレッド（最上部に固定）
  2. 最終返信日時の新しい順
- 各スレッドのカードを開くと、返信一覧が展開表示されます
- 返信は作成日時の **古い順** に表示されます
- 「いいね」は、スレッド本体・各返信に対して個別に押下可能です

#### タスクの管理

- タスク一覧はプロジェクト詳細の「タスク」タブから表示いただけます
- 並び順は登録順（手動の並び順を内部的に保持）にて固定表示されます
- 表示項目: タイトル・担当者・希望日・期限日・ステータス
- タスクごとに、ステータス（未着手 / 進行中 / 完了）をプルダウンにて切替可能です
- 完了済みのタスクはタイトルに取り消し線が表示されます
- タスク詳細ページでは、説明文と添付ファイルの確認が可能です
- 担当者は複数人を割当可能です（プロジェクト参加メンバーから選択）

#### スケジュール（カレンダー）

- プロジェクト詳細の「スケジュール」タブにて、月別のカレンダーを表示いたします
- カレンダーには以下の 4 種類の予定が **色分けにて重畳表示** されます。

| 種別                                           | 色                      | 表示制御            |
| ---------------------------------------------- | ----------------------- | ------------------- |
| プロジェクトスケジュール                       | 青                      | 表示/非表示の切替可 |
| 自分が担当のタスク（期限日基準）               | オレンジ（★マーク付き） | 表示/非表示の切替可 |
| 他メンバー担当のタスク（期限日基準）           | グレー                  | 表示/非表示の切替可 |
| 関連イベント（プロジェクトに紐付いている場合） | 緑                      | 表示/非表示の切替可 |

- 日付をクリックすると、その日の予定一覧がダイアログにて表示されます
- スケジュール項目には以下を設定可能です: タイトル・説明・開始日時・終了日時・終日フラグ・開催場所

#### プロジェクト内ファイル管理

- プロジェクト参加メンバー全員がファイル・フォルダの追加・整理を行えます
- 階層構造（フォルダ内フォルダ）に対応しています
- 詳細仕様はコミュニティ全体のファイル管理機能と共通です

#### 検索仕様

- プロジェクト一覧の検索キーワードは以下のいずれかに一致するプロジェクトを抽出いたします。
  - プロジェクト名
  - プロジェクトの説明
  - 紐付いているタグ名
- 日本語の形態素解析に対応しており、キーワードを含む語句を抽出して検索いたします
- 検索結果ではヒットしたキーワード部分がハイライト表示されます
- ステータス絞り込み・タグ絞り込みと併用可能です

#### 削除時の確認

プロジェクト・メンバー・タスク・スケジュールの削除操作時には、確認ダイアログが表示されます。

## 連携・自動処理

#### 関連イベントとの連動

- プロジェクト作成・編集時に、コミュニティの「イベント」を関連付けることができます
- 関連イベントを設定した場合、スケジュール画面のカレンダーに当該イベントの予定が自動的に表示されます

#### カウント値の自動更新

以下のカウントは関連操作に連動して自動で増減いたします。

- メッセージ（スレッド）の返信数・いいね数
- 返信のいいね数
- メッセージの最終返信日時（並び順制御に使用）

#### 連動削除

- プロジェクトを削除された場合、配下のメンバー・メッセージ・返信・いいね・タスク・スケジュール・ファイル・掲示板コンテンツもすべて削除されます
- メッセージ（スレッド）を削除された場合、配下の返信・いいねもすべて削除されます

※ プロジェクト本体の削除は論理削除（データを保持したまま非表示化）にて実施いたします。

---

## データの取り扱い

- **論理削除**: 削除されたプロジェクト・メッセージ・返信・掲示板コンテンツは画面上では非表示となりますが、データベース上には保持されます（監査・復元目的）
- **物理削除**: タスク・スケジュール・メンバー削除は物理削除（データそのものを削除）にて実施されます
- **メンバー削除の履歴**: 削除されたメンバーは「削除済み」状態に変更され、削除日時・削除理由は記録として残ります
- **削除済みプロジェクトへのアクセス**: 削除されたプロジェクトの URL へアクセスされた場合、「ページが見つかりません」と表示されます

## ご利用にあたっての留意事項

- 削除済みのプロジェクトおよびメッセージは、画面上から復元することはできません（復元が必要な場合はデータベースの直接操作による対応となります）
- プロジェクトの新規作成はシステム管理者・オーナーのみ可能です。一般ユーザーが自発的にプロジェクトを立ち上げることはできません
- プロジェクト参加メンバーへの招待は、システム管理者・プロジェクトホストによる「メンバー追加」操作にて行います（ユーザー自身による参加申請機能には対応しておりません）
- プロジェクト参加メンバー以外のユーザーも、プロジェクト一覧および詳細を閲覧することは可能です（ただし「終了」「中止」状態のプロジェクトは非参加メンバーには非表示となります）
- メッセージ機能はスレッド形式の単純な掲示用途を想定しており、リアルタイムチャット（既読管理・タイピング表示など）には対応しておりません
- スレッドのピン留め・並び替えは、現在の画面 UI からは操作いただけません（運用にて個別対応となります）
- タスクへの担当者通知（メール・プッシュ通知等）は現時点では未対応です
- 「いいね」の件数は通常運用では正確に表示されますが、極めて高い同時実行下では稀に差異が生じる場合がございます
