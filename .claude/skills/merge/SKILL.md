# マージ

作業ブランチから dev への PR 作成・マージ・クリーンアップを自動実行する。

---

## 手順

### 1. 状態確認

以下のコマンドを **並列** で実行する:

- `git branch --show-current` — 現在のブランチ名を取得
- `git status -s` — 未コミットの変更がないか確認
- `git log origin/dev..HEAD --oneline` — dev からのコミット一覧を取得

### 2. ガードチェック

- **現在のブランチが `main` または `dev`** → 「⚠ 作業ブランチから実行してください。」と報告して **終了**
- **未コミットの変更がある** → 「⚠ 未コミットの変更があります。先にコミットしてください。」と報告して **終了**
- **dev からのコミットがゼロ** → 「⚠ dev との差分がありません。」と報告して **終了**

### 3. push 確認

リモートに push 済みか確認する:

1. `git rev-parse --abbrev-ref --symbolic-full-name @{u}` で追跡ブランチを確認
2. 追跡ブランチがない場合 → `git push -u origin {現在のブランチ名}`
3. 追跡ブランチがある場合 → ローカルとリモートの差分を確認し、必要なら `git push`

### 4. PR 作成

1. `git log origin/dev..HEAD --oneline` で dev からの全コミットを確認する
2. 全コミットの内容を分析し、変更全体を要約した PR タイトルを生成する
   - コミットが1つの場合 → そのコミットメッセージをタイトルにする
   - コミットが複数の場合 → 全体の変更内容を要約した Conventional Commits 形式の日本語タイトルを生成する
3. `gh pr create --base dev --title "{生成したタイトル}" --body ""` で dev 向け PR を作成する

既に PR が存在する場合はそれを使う（`gh pr view --json number` で確認）。

### 5. 自動マージ設定・CI 待機

1. `gh pr merge {PR番号} --merge --auto` で自動マージを設定
2. `gh pr checks {PR番号} --watch` で CI 通過を待つ
3. `gh pr view {PR番号} --json state` でマージ完了を確認

### 6. dev 切替・最新化

1. `git checkout dev` で dev に切替
2. `git pull origin dev` で最新化

### 7. 作業ブランチ削除

1. `git branch -d {作業ブランチ名}` でローカルブランチを削除
2. `git push origin --delete {作業ブランチ名}` でリモートブランチを削除

**ブランチ削除失敗時**: 警告を表示するが処理は続行する

### 8. 結果報告

- PR URL とマージ先を表示
- 削除したブランチ名を表示
- 現在のブランチが dev であることを確認表示
- エラーが発生した場合 → エラー内容と対処方法を表示

---

## エラー時の方針

- PR 作成失敗 → エラーを報告して **終了**
- CI 失敗 → PR URL を表示して手動対応を案内し **終了**
- マージ失敗 → PR URL を表示して手動対応を案内し **終了**
- ブランチ削除失敗 → 警告のみ、処理は続行

## 禁止事項

- `--force` を使用した push を行わない
- main ブランチへの PR 作成・マージを行わない
